Privacy

Privacy, plainly.

Software that puts people first starts with not collecting what it doesn’t need. Here is how that works on this website and in our apps.

This website

sparrowtek.com doesn’t use cookies, analytics, advertising or tracking scripts. Its fonts, images and code are all served from this site, so visiting it doesn’t send requests to any other company.

The site is hosted on GitHub Pages. Like most hosts, GitHub may log technical details such as your IP address to run and secure the service. You can read how GitHub handles that information in the GitHub General Privacy Statement.
